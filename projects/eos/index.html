eos is a kernel written from scratch and by hand in NASM assembly, as an exercise in low-level x86 programming. GRUB 2 loads it as a Multiboot 1 kernel in i386 protected mode, and it runs under QEMU.

The work began from The Little Book About OS Development by Erik Helin and Adam Renberg. It has since moved in directions that the book does not cover, but I still use the book as a guiding light.

The current work is a report of the Multiboot 1 information that GRUB gives to the kernel. At boot, the kernel reads the structure and prints its contents to the screen: the memory limits and the memory map, the boot device and its partitions, the command line, the modules, the ELF section headers, the geometry of the BIOS drives, the ROM configuration table, the name of the boot loader, the APM table, the VBE data and the framebuffer.

The Multiboot 1 report structure is purely historical now. However, the code that reads and prints it is good practice in assembly. Each section is read only when its flag bit is set. The arrays give their own sizes. A family of printer routines writes bytes, strings, and decimal and hexadecimal numbers to VGA text mode. Each routine has a banner that lists the registers that it changes and the registers that it keeps.

The eos kernel also defines and loads its own GDT.
