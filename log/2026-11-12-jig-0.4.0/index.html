jig 0.4.0

The first public release: jig now makes its own releases and the releases of the projects that it builds.

Changes
+"jig release" prepares a release, publishes it and compares the published files with the staged ones. It waits for green CI and proves the release commit from a clean clone with an offline build of the source archive.
+"jig terms check" looks for private terms in the product, its commit messages and its built files. "jig privacy scan" looks for serials, host names, addresses, UUIDs and MAC addresses in fixtures and captures.
+"jig upgrade" downloads a release, checks it against its SHA256SUMS and installs it. "jig changelog --since" prints the entries after a version.
+The make targets "version-bump", "package", "package-check" and "source-archive" for the product.
+"jig new" gives a new product a CI workflow that runs "make check" on every push.
